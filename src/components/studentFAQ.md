These are the areas where I particularly want you to improve.

| Topic               | What to improve                                                                                                            |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Promise             | Promise represents eventual completion or failure of an asynchronous operation. It is not simply a callback-hell solution. |
| Async/await         | It makes asynchronous code easier to read. It does not make asynchronous operations synchronous.                           |
| SSR/SSG/CSR         | Clearly explain when rendering happens and where HTML is generated.                                                        |
